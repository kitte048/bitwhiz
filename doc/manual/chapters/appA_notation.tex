\paragraph{Names in the code.} Module \code{temperature} calls the carried
isentrope $e_S$ \code{ec}; module \code{mixture} calls $e_c$ \code{ecs} and
$\thv$ \code{theta}; module \code{burn} keeps $\rho_h$ and $e_{S,h}$ as
\code{rhold} and \code{eshold}. The equation sheets in \code{doc/} write
$\mathcal{H}$ for $\Hug$ and $e_c$ as here.
